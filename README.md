# English For IT — UX redesign prototype

Clickable HTML prototype from a UX/UI course project (Projector): research and redesign of the
english4it.online flow from the homepage to a consultation request.

**Open:** `home.html` (or the GitHub Pages link of this repository).

## Flow
Home → Course match test (start → goal → format → level test) → Result → English For Tech course page → Request → Success

## Screens
| File | Screen |
|---|---|
| `home.html` | Homepage |
| `match-start.html` · `match-goal.html` · `match-format.html` · `match-level.html` | Course match test |
| `match-result.html` · `match-result-sent.html` · `match-result-below.html` | Result and its states |
| `course.html` | English For Tech course page |
| `request.html` · `request-success.html` | Consultation request and success |
